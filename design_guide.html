Design System · 통합 가이드

하나의 시스템,
한 번에 짓는 페이지.

디테일라인 웹사이트의 모든 페이지가 따르는 단일 기준 문서입니다. 토큰 · 타이포 · 레이아웃 · 컴포넌트 · 페이지 구조 · 브랜드 사실을 한곳에 모았습니다. Claude Code는 이 문서만으로 기존 페이지와 동일한 품질·일관성의 새 페이지를 구현할 수 있습니다.

00For Claude Code

이 문서 사용법.

새 페이지·섹션을 구현하기 전 반드시 읽습니다. 이 시스템은 "절제가 곧 일관성"이라는 원칙 위에 세워졌습니다. 새 색·새 폰트·새 그림자를 발명하지 않는 것이 핵심입니다.

  • 1토큰만 사용 — 모든 색·보더는 §01 CSS 변수로. 하드코딩된 hex(#000·#fff 포함)·새 회색 금지.
  • 2두 폰트만 — Pretendard(본문·UI) + Noto Serif KR(디스플레이). 그 외 폰트 도입 금지.
  • 3기존 클래스 재사용 — §05 컴포넌트 카탈로그의 클래스(.btn·.sec-bar·.imgph …)를 그대로 사용. 새 페이지엔 §07 prefix로 고유 클래스만 추가.
  • 4페이지 골격 고정 — Nav → Hero → Breadcrumb → 섹션 → 관련 콘텐츠 → CTA Band → Footer (§06).
  • 5브랜드 사실은 불변 — 전화·슬로건·주소·신뢰지표는 §08 값을 그대로 (절대 변경·창작 금지).
  • 6사진은 placeholder — 자체 촬영 자료 입수 전 모든 이미지 자리는 .imgph 처리. AI·도용 사진 절대 금지.
  • 7SEO·법적·마케팅 필수 항목(§09)이 화면에 자연스럽게 녹아 있을 것 — H1 1개, breadcrumb, alt, 동의 체크박스, 플로팅 CTA 등.
기술 스택. 실서비스는 React 19 + TypeScript + Tailwind 3 SPA(Vite·Vercel). 단, 이 가이드의 모든 토큰·클래스는 프레임워크 독립적인 순수 CSS 변수/클래스로 정의되어 있어 HTML 시안·React 컴포넌트 어디서나 동일하게 적용됩니다. 컴포넌트화 시 클래스명·토큰명을 그대로 유지하세요.
01Tokens

모든 것의 출발점 —
CSS 변수.

아래 :root 블록을 모든 페이지 최상단에 동일하게 선언합니다. 17개 토큰이 전부이며, 페이지마다 새 토큰을 추가하지 않습니다.

04Layout · Spacing

넓은 여백,
고정된 리듬.

컨테이너 한 종류, 섹션 패딩 한 쌍, 명확한 4개 breakpoint. 정보 밀도를 낮추고 여백을 크게 두는 것이 프리미엄 톤의 핵심입니다.

— 레이아웃 기본 
/* 컨테이너 — 전 페이지 동일 */
.container{ max-width:1360px; margin:0 auto; padding:0 32px; }
@media (max-width:720px){ .container{ padding:0 20px; } }

/* 섹션 수직 패딩 + 상단 hairline */
section{ padding:120px 0; border-top:1px solid var(--line); }
@media (max-width:720px){ section{ padding:72px 0; } }

/* 섹션 배경 변주 — 이 둘만 사용 */
.bg-paper{ background:var(--paper); }   /* 살짝 밝은 카드 톤 */
.bg-2{ background:var(--bg-2); }         /* 살짝 진한 톤 */
/* 다크 섹션은 background:var(--dark); border-top:0 */
